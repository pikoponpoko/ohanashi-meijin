# 集中モード・全画面と安全な章移動

main `e0359687ff29f16a86be8746d49f3d6b9b14af18` からの独立機能。前回のPWA・空行整理等の作業ブランチを変更・再実装しない。

## 操作

- 既存の集中モードボタン / CtrlまたはCmd+Shift+Fでアプリ内集中モードを切替える。常に見える「集中モードを終了」ボタンでEscなしでも戻れる。
- 集中モードの「全画面」は別操作。Fullscreen APIの許可があればブラウザの全画面へ移る。未対応・拒否時はアプリ内集中モードを継続し、画面上から解除できる。ブラウザ側で全画面を解除した場合も通常表示へ戻る。
- 集中モードまたはブラウザ全画面中だけ、**Alt+PageUp / Alt+PageDown** で前/次の章。画面上の矢印でも操作可能。範囲選択用のShift+矢印、Ctrl/Cmd+Z、既存Alt+1/2/3は維持。OS/ブラウザがキーを渡さない場合は画面上のボタンを使う。
- IME変換中、dialog内、エディタ外の入力欄では章移動しない。キーリピートで連続移動しない。先頭/末尾で折返さない。
- 未保存の変更は章移動前にsaveし、失敗した場合は現在章と未保存本文をそのまま保持して移動を中止。既存の履歴・カットID・保存形式を変更しない。複数タブ同時編集の競合解決は追加していない。

## ピンチ操作

文字設定の「専用領域のピンチで集中モードを切り替える」は初期OFF。明示的にONにすると画面端の「集中モード操作」領域が表示される。領域上の二本指を広げると開始、狭めると終了。指間距離24px以上の変化、比率1.35以上/0.7以下、1.5秒以内で判定する。小さな動き・キャンセル・IME中は切替えない。専用領域だけが `touch-action:none` を持ち、本文の通常ピンチズームや既存の指Undo/Redoを奪わない。

専用領域はエディタ外に配置。切替で原稿・履歴を書き換えない。設定は原稿と別の `scenario-meijin-v1-view-options-v1` キーへ保存し、容量不足で保存できない場合は切替設定を元に戻す。ピンチを使えない端末でも通常ボタンを利用できる。
