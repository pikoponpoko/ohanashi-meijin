# プリプロTXTのカット境界読み込み修正

2026-10-24 JST。main `e0359687ff29f16a86be8746d49f3d6b9b14af18` から独立した `fix/prepro-txt-import`。前回のPWA・空行削除・空白開始・画面改善・集中モードのブランチは保持する。プリプロ側は参照のみで変更せず、自動同期や素材の紐付けを追加していない。

## 原因と修正

プリプロ `js/linestext.js` は `# C1` のように空白付きの番号を出力する。現行おはなしの保存形式用の境界判定は `#C1` のみなので、TXTの番号が普通の本文になり、冒頭に別の内部カットが作られた。また、先頭空行・旧説明ヘッダーの前にも内部カットを追加していた。未編集の初期章にTXTを追加すると初期章の空カットも残り、作品全体の番号がずれた。

- 外部TXT/貼付専用の `ScriptModel.importText/importChapter` を追加。保存済みJSON用のvalidate/migrate規則は変更しない。
- 単独行の `#C1` / `# C1` / `# C 1A`、英字枝番、`-数字` / `.数字` の枝番を境界へ正規化する。数字の重複や欠番で結合・並替えせず、出現順で独立したUUIDを生成。表示は既存の全章連番処理で採番し、元の番号を内部IDにしない。
- BOM/CRLFと先頭余白を処理。最初の実境界の前が既知のプリプロ説明ヘッダーと空行だけの場合に限り除去する。`2a09b1e` の説明除去前の実装で確認した、脚本管理/台詞一覧の既知の保存/コピー案内を対象にする。不明な前書きや本文中の `#C1`、明示的な空カットは保持する。
- ファイル読み込みは、無題・著者なし・一章だけ・章名が既定「新しい章」・空本文・カット1個の初期枠に限り置換する。章IDと作品の設定は維持。それ以外は新しい章として追加し、既存章やIDを維持する。既存の意図的な空カットを勝手に消さない。
- 外部テキストの貼付では、空章またはエディタ全選択置換に限り余分な初期境界を残さない。空章の最初のIDは再利用する。内部clipboardのcut/copy用ID引継ぎ規則は変更しない。
- 自動修正は元の境界/UUIDを保持。Undoはインポート/貼付の一操作を戻し、Redoで同じIDへ復元する。
