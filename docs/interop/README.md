## 共通交換JSONの扱い

共通交換形式の正式合意はまだない。[PR #3](https://github.com/pikoponpoko/ohanashi-meijin/pull/3)の `meijin.script-exchange / 0.1-draft.1` は[既存原案](DRAFT.md)・[Schema](ohanashi-prepro.schema.json)・[サンプル](samples/baseline.json)を変更せず維持する。今回追加したsoundCuesは保存v2の任意項目であり、draft.1へ新しいkindを足していない。draft.1ではaction.rawの接頭辞を既存パーサーで読める。

将来、独立music／seブロック・永続段落ID等を交換仕様へ導入する場合は別版で合意し、旧版の受信アダプターを残す。UIや内部DOMの変更を外部JSONへ直接漏らさない。送信アダプターで既定の形式へ変換し、契約試験で互換性を確認する設計を維持する。作品ID・revisionの分岐・段落IDは引き続き未確定で、今回新設しない。

カットは永続ID、表示番号は表示専用、soundCuesのlineは位置参照であり永続IDではない。柱は場面情報、ト書きは各論理動作、台詞内改行は1発話内の折り返しとする。差分の追加・削除候補・移動・本文変更はプレビュー・手動確認・Undoを経て確定し、既存画像・音声・尺・カメラ等を勝手に変更しない。

## 作品ID（保存v2の任意項目 `workId`）

2026-10-26追加。保存v2のトップレベルに文字列 `workId` を持つ。versionは2のまま。

- 読み込んだJSONに有効な `workId`（空でない200文字以下の文字列）があれば変更しない。
- 無い場合は先頭章IDから `work-<章ID>` を導出する。同じ未保存の旧JSONを何度開いても同じ値になり、次の自動保存・JSON保存で確定する。
- 新しい作品・TXT/MDを開いた場合は新しい章IDから導出するため、別作品として扱われる。
- 「別名で保存」で複製したJSONは同じ `workId` を持つ。分岐・リビジョンは未定義。
- カットID・章ID・表示番号・soundCuesは変更しない。

プリプロmain `11ba477` とPR #23 `3572c15` の `readScript` は `workId` の有無で同じカット・行を返す（未使用のため無視される）。プリプロ側で作品照合に使う場合、既存の連携記録は `externalId:null` なので、そのまま比較すると既存作品の更新を拒否する点に注意。
